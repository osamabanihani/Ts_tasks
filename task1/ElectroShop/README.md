# ElectroShop - Angular Day 1

This is a simple student solution for the Day 1 task.

## How to run

1. Open this folder in VS Code.
2. Open the Terminal.
3. Write `npm install` and press Enter.
4. Write `npm start` and press Enter.
5. Open http://localhost:4200/ if it does not open automatically.

## Main files

- `src/app/app.component.ts` - variables, arrays, `if`, and `for` loop.
- `src/app/app.component.html` - page using Angular interpolation.
- `src/app/app.component.css` - basic design.
