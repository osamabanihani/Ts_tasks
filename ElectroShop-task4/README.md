# ElectroShop - Task 4

Continuation of the supplied Day 3 project. Header, navbar, product details, signals, input/output, editable fields and shopping cart are retained. Task 4 changes are in `src/app/product-list/`.

## Run

```bash
npm install
npm start
```

Open http://localhost:4200.

## Test Task 4

Change `orderStatus` in `product-list.component.ts` to Pending, Processing, Shipped, Delivered or another string. Change `selectedCategory` to All Products, Electronics or Accessories. Category filtering is not required. Buy Now shows the original selection alert; the existing Day 3 Add to Cart remains in Product Details. The Day 3 demonstration uses its own two products; Task 4 lists the eight required examples separately.

Do not commit node_modules, .angular or dist.
